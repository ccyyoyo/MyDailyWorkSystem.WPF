# 日常工作管理系統 PRD

## 0. 專案概述（Project Overview）
- 系統名稱：日常工作管理系統（個人 PC 端，單人使用，不支援多帳號）
- 目標：提供一套以「個人日常工作流程」為核心的管理工具，整合任務、專案、行程與紀錄，提升工作追蹤與執行效率。
- 平台：Windows 10 / Windows 11 桌面應用程式
- 儲存：全數據在本機（Local），使用 SQLite

## 1. 使用者情境（User Scenarios）
### 1.1 每日工作流程
- 開機啟動系統即進入「儀表板」，包含：今日必辦任務、待辦任務、週重點專案、快速新增。
- 快速操作：完成功能、調整狀態、修改內容、標註延期（選填）。

### 1.2 任務管理流程
- 新增任務並設定屬性（分類、優先度、狀態、預估工時等），可在列表中直接更改狀態/日期/優先度，無須進入詳情。

### 1.3 專案管理流程
- 每個專案彙整相關任務與筆記，提供專案總覽、進度與警示指標。

### 1.4 行程紀錄流程
- 可登錄訪談/會議/行程，並決定是否關聯到特定專案或任務。

### 1.5 紀錄/筆記流程
- 每日入口可快速新增電話紀要、會議重點，並可關聯至專案、任務、人員或議題。

## 2. 功能規格（Functional Requirements）
### 2.1 儀表板（Dashboard）
- 2.1.1 今日任務：顯示「到期日為今日」的任務，支援快速切換狀態（未開始/進行中/已完成），並可調整到期日與優先度。
- 2.1.2 待辦任務：顯示所有未完成任務，支援篩選（專案、嚴重度、標籤）。
- 2.1.3 本週焦點專案：可勾選本週需要關注的專案，顯示未完成、逾期、即將到期任務數。
- 2.1.4 快速新增：以彈窗方式新增任務或紀錄。

### 2.2 任務管理（Task Management）
- 欄位：名稱（必填）、所屬專案（可空）、類型（如：訪談、約會、研究、待處理、文件整理等）、優先度（1~5）、狀態（未開始/進行中/已完成/延期）、預估工時（可空）、實際完成時間（自動記錄）、標籤、詳細註記、附件（以本機檔案路徑儲存）。
- 列表/篩選：支援篩選（專案、優先度、標籤、狀態），排序（狀態、優先度、建立日期、自訂），批次操作（更改狀態、調整日期、切換專案）。
- 詳情：點擊任務後於右側顯示詳細資訊，不跳離列表。

### 2.3 專案管理（Project Management）
- 欄位：名稱（必填）、類型（如：外部委託、礦業、政府專案、內部專案等）、狀態（規劃中/進行中/待決策/結案）、預計結束日、實際結束日、主要對象（如：地主、建商、設計師）、說明、關鍵風險、標籤。
- 功能：彙整所屬任務並顯示專案總覽（未完成/逾期/即將到期任務數），顯示近期待辦、專案筆記、會議紀要、決策事項。

### 2.4 行程/日曆（Schedule / Calendar）
- 視圖：月/週/日。
- 欄位：標題、起訖時間、所屬專案（可空）、備註。
- 功能：行程可關聯任務/專案；行程提醒（至少支援首選提醒時間）。

### 2.5 紀錄 / 筆記（Logs / Notes）
- 欄位：自動時間戳；內容可關聯多個項目（會議/任務/人員等）。
- 功能：支援全文搜尋與條件篩選（專案、日期、類型），可按關聯對象檢視。

### 2.6 搜尋系統（Search）
- 支援指定範圍快速定位：任務名稱/註記、專案名稱、專案筆記、紀錄內容、標籤。
- 篩選條件：專案、狀態、標籤；搜尋回應需在 1 秒內（以 PC 本機執行為前提）。

## 3. 非功能需求（Non-Functional Requirements）
- 3.1 效能：數千筆任務與紀錄仍需流暢；搜尋/篩選結果 1 秒內返回。
- 3.2 安全：資料庫可選擇加密；系統/設定可設定啟動密碼與強度檢查。
- 3.3 資料存儲：使用 SQLite，資料存於本機指定資料夾，不使用雲端。
- 3.4 備份：提供匯出/備份，將資料庫檔案複製到指定資料夾；每日提醒備份，可選擇週期性擴充。
- 3.5 擴充性：未來可擴充至多裝置同步、API / Web 介面、推播通知；由工程師評估與維護。

## 4. 建議技術方案（供工程師參考）
- 預設堆疊：C# + .NET（WPF 或 WinUI）+ SQLite。
- 工程師可調整，但需符合主流、穩定且易維護的技術方案。

## 5. UI/UX 線框規劃（Wireframe Guidelines）
- 5.1 主要版面：左側主選單（儀表板、任務、專案、行程、紀錄、設定）；右側為內容區域，上方搜尋/篩選，中間列表，右側細節，點選即可顯示詳細資訊。
- 5.2 互動原則：新增以彈窗進行；任務狀態、優先度可在列表直接調整；介面簡潔，減少頁面跳轉。
